# git

This directory contains sample files organized by programming language, used to practice Git workflows such as staging, committing, and pushing changes.

## Directory Structure

```
git/
├── bash/
│   ├── best     # Prints "This School is so cool!"
│   └── school   # Prints "School"
├── c/
│   └── c_is_fun.c   # C source file
├── js/
│   ├── index.js     # JavaScript file
│   └── main.js      # JavaScript file
└── up_to_date       # Contains the git pull command
```

## Files

### bash/

| File   | Description                     |

### up_to_date

Contains the `git pull` command, used to demonstrate keeping a local repository in sync with the remote.
