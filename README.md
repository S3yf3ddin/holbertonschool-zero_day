## Description

This repository is part of the **Holberton School** curriculum and covers the **Zero Day** project.  
It focuses on getting comfortable with **Git** and **GitHub** as core tools for source control and collaboration.

The project walks through creating a repository, making commits, pushing code, and keeping a local copy in sync with the remote.

## Learning Objectives

By the end of this project you should be able to explain:

- ✅ What is source control and why it matters
- ✅ How to create a Git repository locally and on GitHub
- ✅ How to stage (`git add`) and commit (`git commit`) changes
- ✅ How to push changes to a remote repository (`git push`)
- ✅ How to pull the latest changes from a remote (`git pull`)
- ✅ How to work with branches and resolve merge conflicts
