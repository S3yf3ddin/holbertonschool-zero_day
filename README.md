# holbertonschool-zero_day

This repository is part of the Holberton School curriculum and covers the **Zero Day** project — an introduction to source control using Git and GitHub.

## Repository Structure

```
holbertonschool-zero_day/
├── README.md        # This file
└── git/             # Git project: examples across multiple languages
    ├── bash/        # Bash shell scripts
    ├── c/           # C source files
    ├── js/          # JavaScript source files
    └── up_to_date   # File used to practice git pull
```

## Learning Objectives

- Understand how to create and manage a Git repository
- Stage, commit, and push changes to GitHub
- Work with branches and handle merge conflicts
- Keep a local repository up to date with `git pull`
